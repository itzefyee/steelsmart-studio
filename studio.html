From intent to an editable assembly.

The local demo extracts dimensions and structure types from your brief, then builds a deterministic member graph. Every beam, quantity, and export comes from that graph.

Supported concepts: portal frames, open canopies and three-level storage racks. Profile masses use nominal section data. Base plates and bolts are visual connection details and are excluded from member totals. This workspace does not perform load analysis or code compliance checks.

OBJ exports member envelopes for interoperability. JSON preserves editable parameters and the full member graph. Use CSV for a preliminary material schedule.
