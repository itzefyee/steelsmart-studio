# SteelSmart Studio
<!-- impeccable:product-schema 1 -->
## Platform
Web.
## Users and purpose
Engineers exploring parametric steel concepts; portfolio visitors evaluating frontend and generative CAD engineering. User explicitly selected an interactive CAD / AI studio.
## Stack
Existing workspace conventions: HTML, CSS, ES modules and Node. Three.js is vendored for self-contained WebGL rendering.
## Positioning
Prompt-guided parametric steel assemblies, inspectable member geometry, live quantities and portable model exports in one workspace.
## Operating context
Local browser showcase. No accounts, paid services or backend credentials. Local deterministic language rules are labeled. No certified structural analysis or invented commercial claims.
## Evidence on hand
Reference page https://steelsmart.vercel.app fetched 2026-10-02: AI CAD generation, analysis, recommendations and steel marketplace.
## Product principles
Show working geometry. Derive quantities from geometry. Keep outputs honest and editable. Support keyboard and mobile.
