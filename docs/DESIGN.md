# SteelSmart Studio design

## Showcase experience

The default route is now an Experience surface: "Steel as sculpture." A graphite stage (#171a1b), off-white type (#f1f0e9), and signal orange (#f5683c) extend the studio's steel and orange identity. Pale editorial sections create deliberate contrast between the dark 3D story and live configurator. Self-hosted Manrope sets large 96px maximum headings, with restrained numerical and dimensional labels.

The opening is a real WebGL bolted connection. A sticky three-chapter scroll sequence separates its parts and replaces it with a complete steel structure. No scroll hijacking. Direct orbit, wireframe, finish choice, and separation controls remain functional. Touch rotation is opt-in so the drawing does not consume page scrolling. Reduced motion uses explicit chapter buttons on a non-sticky stage.

The live playground owns its own lazy-initialized renderer and hands its exact configuration to studio.html. Both renderers draw only on state changes and stop offscreen/when hidden. The final orange invitation leads directly to the working studio. No imaginary customer logos, performance statistics, or AI capability claims.

The Design Lab adds one compact tool rail to that drawing: Explore, Assembly, Section and Compare. Context controls occupy a single strip; secondary sharing and image export stay at the right. Assembly labels connect progress to real members. A warm orange plane makes the section legible. Comparison uses a muted green reference A and orange current design B, with a quantitative ledger below. Views share scale and rotation; on phones they stack. There are no nested workspaces or blocking dialogs. Shared links restore the design; local PNG study sheets preserve the current view. Comparison quantities and the illustrative sequence make no engineering approval claims.

## CAD studio

Mode: Operate with the 3D artifact leading. Direction: architectural drafting sheet, pinned to the SteelSmart engineering reference and approved interactive studio.

White working surfaces, pale gray drawing field, ink #202d40, navy #344b75 structural geometry, orange #db4b28 primary action, teal #267361 valid state. Manrope regular and semibold self-hosted. Monospace only for measurements. Tight 12–14px inspector typography, 28px workspace title. Thin neutral rules separate regions; rounded surfaces only where they group an actual task.

Desktop: 64px top navigation, workspace heading, 290px prompt pane, flexible viewport, 260px property inspector, full-width lower material schedule. Mobile: same reading order with a useful 430px viewport and collapsible inspectors. The signature interaction is transforming a dimensional steel assembly through a prompt or slider, with quantities and exports changing from the same source of truth.

The studio tool rail adds Design brief, Inspect, Materials, Explore and Review. Practical inspection leads on entry; material planning is adjacent. The active task occupies the left pane while the model and parameters remain available. Larger results such as alternatives, cutting layouts and the three-view sheet occupy a full-width surface below the model. Focus view temporarily expands the drawing; the command palette provides a keyboard route to the same visible controls.

Member rows use aligned IDs, profiles, lengths and masses, with orange selection shared by the 3D model. Mass coloring has a numerical legend. Cutting bars use proportional lengths, quiet offcut regions and clickable member labels; oversize members remain explicit. Review notes are compact, local records, and the drawing sheet follows the existing drafting typography. On mobile the model leads, then task controls and parameters; long lists and drawing sheets scroll inside their own region without overflowing the page.
