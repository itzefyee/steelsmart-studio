# A more useful playground

Add four tightly connected capabilities to the existing dark interactive playground: scrub/play assembly of the real member graph; a movable world-correct section plane; immutable A/B design pinning with synchronized views and actual quantity differences; and portable design links plus PNG study exports. All features remain concept exploration, not a construction method or capacity check.

Preserve the established typography and visual world. A single tool rail switches the same drawing between Explore, Assembly, Section and Compare. Context controls live below the rail. Comparison adds a split drawing and an adjacent quantitative ledger; no full-screen modal or unrelated dashboard.

Separate pure assembly/comparison/link logic in lab-model.js, renderer changes in experience-scene.js and UI orchestration in design-lab.js. Use one additional renderer only while comparing. Pause playback when hidden/offscreen and when reduced-motion changes. Keyboard and native range controls expose every action.

Verify real ordered member coverage, comparison math, link round-trips, clipping pixels, playback/scrub behavior, stable pinned baseline, synchronized orbit, PNG payloads, mobile layout and existing studio handoff. Inspect desktop/mobile in one batch, fix together, then confirm once.
